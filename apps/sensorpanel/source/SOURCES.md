# Corresponding source: Sensor panel

`sensorpanel.c` is the whole program, copied from why2025-linux
`sdapps/sensorpanel/` at commit `40e60f6` (it was `overlay-src/sensorpanel.c`
of the OS image before). The toolchain and the build script are in
[toolchain/](../../../toolchain/README.md).

Build: put it in `sdapps/sensorpanel/` next to `toolchain/sdapps-build.sh`
and run `sdapps-build.sh sensorpanel`.
